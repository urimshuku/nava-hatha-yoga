# Topic Clusters — Nava Hatha Yoga

**Date:** 10 August 2026  
**Companion docs:** `KEYWORD-ARCHITECTURE.md`, `PAGE-KEYWORD-MAP.md`, `CONTENT-GAPS.md`  

This document defines seven topic clusters. Each cluster has one **pillar** (or dual commercial + education pillars where needed), supporting **cluster pages**, and required **internal link rules**.

---

## Cluster design principles

1. One cluster = one subject domain users research together.  
2. Pillar pages earn the broadest commercial or category query for that domain.  
3. Supporting pages deepen intent without stealing the pillar’s primary keyword.  
4. Every cluster must end in a **registration path** (Contact / Events / Program CTA).  
5. Cross-links between clusters are allowed when they help the user choose a practice — use the **target page’s primary** as anchor text.  

```
                    [Home: Classical Hatha Yoga Albania]
                                   |
       ------------------------------------------------------------
       |            |            |            |            |       |
   Surya Kriya  Angamardana  Yogasanas   Upa Yoga   Bhuta Shuddhi  Retreats
       |            |            |            |            |       |
   (supports)   (supports)   (supports)  (supports)  (supports)  (local/immersive)
                                   |
                            [Contact / Events]
```
